# Culto

Application web de culture quotidienne : deux livres et quatre analyses par jour, en format Complet ou Express, avec deux mots de vocabulaire par semaine.

- `index.html`, `app.js`, `app.css` : l'application (installable sur iPhone via Safari › Partager › Sur l'écran d'accueil).
- `editions/` : une édition par jour au format JSON, et `index.json` qui les liste.
- `CULTO_BRIEF.md` : le cahier des charges suivi pour générer chaque édition.
- `scripts/validate.py` : vérification d'une édition avant publication.
